# 🚀 AERU 개발팀 모집

> **학생이 만들고, 학생이 운영하는 개발팀**

AERU는 “기술은 사회의 문제와 우리 주변의 불편을 해결하기 위해 존재한다”는 가치 아래, 학생 개발자들이 모여 다양한 프로젝트를 만들어가는 개발팀입니다.

우리가 일상에서 마주하는 작은 불편부터 사회가 가진 문제까지, 기술을 통해 해결할 수 있는 방법을 고민하고 이를 실제 서비스로 구현하기 위해 여러 프로젝트를 준비하고 있습니다.

개발뿐만 아니라 기획, 디자인 등 다양한 분야의 학생들이 함께 참여하며, 아이디어를 직접 현실로 만들어내는 것을 목표로 합니다.

현재 AERU와 함께 이러한 프로젝트를 만들어갈 **학생 프론트엔드 개발자 및 디자이너**를 모집합니다.

---

## 💻 Frontend Developer

* 관련 소프트웨어 고등학교 재학 / 동아리 활동 등 학생의 신분 하에 해당 직군과 연관된 조직적 경험을 하고 계시는 분
* TypeScript / JavaScript를 기반으로 웹 프론트엔드 개발이 가능한 분
* React / Next.js를 활용하여 웹 서비스를 개발할 수 있는 분
* Git / GitHub을 활용한 협업 경험이 있는 분
* 단순한 토이 프로젝트를 넘어 실제 사용자를 대상으로 하는 웹 서비스를 만들어본 경험이 있는 분
* 프로젝트에 적절한 기술을 직접 고민할 수 있는 분
* 개발 과정에서 사용자 경험과 UI/UX를 함께 고민할 수 있는 분

### 🛠️ 이런 기술을 사용합니다

**Required**

* TypeScript
* React
* Next.js
* Git / GitHub

**Preferred**

* Tailwind CSS
* Figma

- 이외 기술은 선호하시는 기술에 맞춰 가겠습니다.

기술 스택을 전부 알고 있을 필요는 없습니다.
일부 기술만 경험했더라도 실제 프로젝트를 만들어본 경험과 성장 가능성을 중요하게 봅니다.

## 🎨 Designer

AERU의 서비스를 직접 디자인하고 사용자 경험을 만들어갈 학생 디자이너를 찾습니다.

### 이런 분을 찾습니다

* Figma를 활용하여 웹 서비스의 UI를 설계하고 제작할 수 있는 분
* 단순히 예쁜 화면을 만드는 것을 넘어 사용자 경험을 고려하여 디자인할 수 있는 분
* 웹 서비스의 레이아웃, 타이포그래피, 컬러, 컴포넌트 등에 대한 기본적인 이해가 있는 분
* 서비스의 목적과 사용자를 고려하여 화면과 사용자 흐름을 설계할 수 있는 분
* 개발자와 원활하게 소통하며 실제 구현을 고려한 디자인을 할 수 있는 분
* 개인 프로젝트, 학교 활동, 동아리 등에서 UI/UX 디자인을 직접 진행해본 경험이 있는 분
* 자신의 디자인에 대해 "왜 이렇게 디자인했는가?"를 설명할 수 있는 분


### 우대

* Figma 사용 경험
* 웹 또는 앱 UI/UX 디자인 경험
* 디자인 시스템 제작 경험

## 우리는 '학생 개발자'를 찾습니다.

AERU는 완성된 실력만을 갖춘 사람을 찾지 않습니다.

배운 것을 실제로 만들어보고 싶고, 혼자서가 아니라 좋은 팀과 함께 더 큰 것을 만들어보고 싶은 학생을 기다립니다.

학교에서 배운 기술을 실제 서비스에 적용해보고,
새로운 기술이 필요하다면 함께 찾아보고 공부하며 해결합니다.

기획부터 디자인, 개발, 배포와 운영까지 직접 경험하면서
단순한 프로젝트를 넘어 실제로 누군가가 사용하는 서비스를 만들어가는 것이 AERU가 추구하는 방향입니다.

무엇보다 AERU는 **학생이라는 점을 중요하게 생각합니다.**

서로 다른 경험과 기술을 가진 학생들이 모여 함께 배우고 성장하는 것,
그리고 학생의 위치에서 할 수 있는 가장 좋은 결과물을 만들어내는 것.

**그것이 AERU가 생각하는 학생 개발팀입니다.**
